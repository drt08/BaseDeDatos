# Base de Datos Empresa

Aplicación académica desarrollada en Python para cargar información desde archivos Excel, almacenarla en MySQL y consultarla mediante una interfaz creada con Streamlit.

## Funciones

- Cargar información de empleados, proyectos, salarios, clientes, proveedores, capacitaciones y departamentos.
- Visualizar las tablas de la base de datos.
- Ejecutar consultas SQL para relacionar y analizar la información.

## Tecnologías utilizadas

- Python
- Streamlit
- MySQL
- Pandas

## Archivos principales

- app.py: contiene la interfaz y las opciones de la aplicación.
- data_helper.py: administra la conexión con MySQL y las operaciones con los datos.

## Estado del proyecto

Proyecto académico en proceso de documentación y mejora.
